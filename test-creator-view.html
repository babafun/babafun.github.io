✅ Semantic HTML Elements Used

<main> - Used as the main container with role="main"
<header> - Used for view headers and song headers
<section> - Used for grouped content (creator groups)
<article> - Used for individual song cards with role="article"
<footer> - Used for disclaimers and song actions
<h1>, <h2>, <h3> - Proper heading hierarchy maintained
<ul>, <li> - Used for lists with proper role="list" and role="listitem"

✅ ARIA Labels and Accessibility Features

aria-labelledby - Song cards linked to their titles
aria-describedby - Song cards linked to their metadata
aria-label - Descriptive labels for badges, links, and interactive elements
aria-live="polite" - Used for dynamic content updates
aria-hidden="true" - Used for decorative elements (icons, symbols)
role="status" - Used for creator-friendly badges and empty states
role="region" - Used for grouped sections with proper labeling
role="group" - Used for song grids with descriptive labels
role="contentinfo" - Used for footer disclaimer content
role="note" - Used for informational content
